# Icon Files

This extension requires icon files for the Chrome extension store. You can create simple icons or use placeholder images.

## Required Sizes
- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels  
- `icon128.png` - 128x128 pixels

## Quick Solution

You can create simple colored square icons or download free icons from:
- https://www.flaticon.com
- https://icons8.com
- Or create simple PNG files with any image editor

For now, the extension will work without icons, but Chrome may show a warning. The extension functionality is not affected.

## Creating Simple Icons

You can use any image editor or online tool to create simple icons. A simple approach:
1. Create a square image with a clipboard or table icon
2. Use a tool like GIMP, Photoshop, or online editors
3. Export as PNG in the required sizes
