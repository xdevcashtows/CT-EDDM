# Quick Installation Guide

## Step-by-Step Instructions

1. **Download the Extension**
   - Make sure you have all the files in the `CT EDDM extension` folder

2. **Open Chrome Extensions Page**
   - Open Google Chrome
   - Type `chrome://extensions/` in the address bar and press Enter
   - OR go to: Menu (⋮) → Extensions → Manage Extensions

3. **Enable Developer Mode**
   - Toggle the "Developer mode" switch in the top-right corner

4. **Load the Extension**
   - Click the "Load unpacked" button
   - Navigate to and select the `CT EDDM extension` folder
   - Click "Select Folder"

5. **Done!**
   - The extension is now installed
   - Visit https://eddm.usps.com/eddm/select-routes.htm to use it

## Troubleshooting

- **"Manifest is not valid JSON"** - Make sure all files are in the same folder
- **Extension doesn't appear** - Make sure Developer mode is enabled
- **Popup doesn't show** - Make sure you're on the correct EDDM page
